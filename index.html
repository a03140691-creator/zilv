备份与恢复

数据只存在这台设备的浏览器里。清浏览器数据、换浏览器、换手机前，先导出备份。

安装到手机 / 电脑

iPhone（Safari）安装步骤：

1. 把整个「自律积分」文件夹上传到免费静态托管（推荐 Netlify Drop：app.netlify.com/drop 拖进去就上线）；

2. 用 Safari 打开你的网址（必须是 https:// 开头）；

3. 点底部中间的「分享」按钮（方框＋向上箭头）；

4. 菜单往下滑，点「添加到主屏幕」→ 右上角「添加」；

5. 回主屏幕点「自律积分」图标，就是独立 App 了。

详细图文说明见《安装与打包指南.md》

安卓 / 电脑（Chrome / Edge）安装步骤：

1. 把整个「自律积分」文件夹上传到免费静态托管（推荐 Netlify Drop）；

2. 用 Chrome 打开 https:// 网址；

3. 点右上角菜单 ⋮ →「安装应用」（或「添加到主屏幕」）；

4. 桌面 / 主屏幕出现图标，点击即独立窗口运行。

打成 APK 安装包的方法见《安装与打包指南.md》

现在是本地文件方式打开（file://）。浏览器规定：Service Worker 和 PWA 安装必须走 https:// 或 localhost，本地双击不支持安装。

所有记账功能不受影响，正常用。要装成 App 的话，按《安装与打包指南.md》把文件夹传到 Netlify Drop 再装。

✅ 已以独立 App 模式运行

积分规则

改规则：打开 index.html，最上面的 CONFIG 配置区就是全部参数。

💡 存钱、转入资产账户不算消费，不扣积分；只有实际花出去的钱才按 1 元 = 10 积分扣。
